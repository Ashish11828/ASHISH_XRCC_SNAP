# Pulse — Spectacles Project

## Overview

Lens Studio project snapshot forked from [jackyydai/LAHack2025-Pulse](https://github.com/jackyydai/LAHack2025-Pulse). This repository retains the original project layout and history.

## Project files

- `pulse.esproj`: Lens Studio project.
- `Support/`: project type definitions.
- `jsconfig.json` and `tsconfig.json`: script configuration.
- `PluginsUserPreferences/` and `Workspaces/`: exported editor settings.

The current tree does not include an `Assets/` directory, so it should not be treated as a complete runnable Lens. Restore the matching original assets before attempting to reproduce the experience. Hardware behavior and project compatibility have not been tested here.
